# FHGFF3 header documentation

The authoritative FHGFF3 documentation is maintained in the shared publication
repository:

- <https://github.com/FAIR-bioHeaders/FAIR-bioHeaders-Specification/blob/main/docs/FHGFF3.md>

`FHGFF3.md` in this directory is a byte-for-byte development copy of that file at
the pinned revision recorded in [`../provenance.json`](../provenance.json). It is
kept here so the header contract can be read and discussed next to the model and
vectors. Edit the shared file, not this copy, and re-import deliberately (see
[`../PROVENANCE.md`](../PROVENANCE.md)).

The header rules also rely on the shared format rules (R1–R12) in the publication
repository's `docs/FORMAT.md`.
